# E-Commerce Sales Analysis – Tableau

An interactive **Tableau dashboard** designed to analyze e-commerce sales, profit, products, and customer trends.

## 📊 Project Overview

This project uses data analysis and Tableau visualizations to understand e-commerce business performance and identify important sales and profit trends.

## 🛠️ Tools Used

- Tableau
- Excel
- Data Visualization
- Data Analysis

## 🔍 Key Analysis

- Sales and Profit Analysis
- Product Performance
- Customer Trends
- Category-wise Performance
- Sales Trends
- Interactive Filters

## 📈 Dashboard Features

- Interactive charts and KPIs
- Filters and slicers
- Sales and profit comparison
- Product and category analysis
- User-friendly dashboard

## 📁 Project Files

- Dataset – Source e-commerce data
- Tableau Workbook – Interactive dashboard
- Dashboard Screenshot – Preview of the dashboard

## 💡 Key Outcome

The dashboard transforms raw e-commerce data into meaningful insights to support better business decisions.
